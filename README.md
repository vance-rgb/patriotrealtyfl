# Patriot Realty FL

Dynamic Next.js site for `Patriotrealtyfl.com`, ready for Vercel.

## Local setup

```bash
npm install
npm run dev
```

## Dynamic pages

Edit `lib/site-data.js` to change the navigation, services, featured areas, and dynamic pages.

Current dynamic URLs:

- `/buy`
- `/sell`
- `/relocate`
- `/areas`

## Vercel domain setup

1. Create or import this project in Vercel.
2. Open the project's **Settings > Domains**.
3. Add `patriotrealtyfl.com` and `www.patriotrealtyfl.com`.
4. Update DNS at the domain registrar using the records Vercel provides.

Vercel Hobby is for personal/non-commercial projects. Use Pro if this is a business website for real estate lead generation or brokerage services.
